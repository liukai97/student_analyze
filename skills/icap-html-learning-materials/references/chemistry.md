# 化学学习材料

## 使用范围

制作化学学科的 HTML 学习材料时读取本文件。这里补充化学专用的表征、图形化和准确性要求；ICAP学习路径、练习设计、HTML交付与验证仍以主 `SKILL.md` 为准。

当前重点是结构式和反应图示。将来新增化学专用规则时继续放在本文件中，不要把化学细节堆入主技能。

## 化学图形表征原则

1. **图形服务于化学关系。** 只有当图形能帮助学生识别原子连接、官能团差异、空间关系或成键变化时才使用。装饰性插图不应挤占讲解与练习空间。
2. **保留化学符号。** 图形旁保留学生需要读取和书写的分子式、结构简式、方程式、条件与术语。安排从图到符号、从符号到图的转换，避免学生只会认图。
3. **选择性图形化。** 优先呈现纯文本难以表达的局部关系、关键变化和典型结构；短小且易书写的表达继续使用文本。
4. **准确性高于视觉风格。** 优先使用内嵌 SVG 或化学专用软件的确定性输出。需要逐原子、逐键准确的图示不得依赖生成式图片模型的视觉可信度。
5. **信息不能只靠颜色。** 可用颜色引导注意，但同时使用标签、线型、箭头或文字说明。图形在灰度打印时仍应可理解。
6. **可访问且可打印。** SVG使用明确的 `viewBox`、`role="img"`、`title` 和 `desc`；图片提供替代文字。检查窄屏缩放、打印清晰度和原子标签字号。

图示较少时可内嵌在单个 HTML 中。图示数量多或需要复用时，放入交付目录的 `assets/molecules/` 并使用相对路径；最终产物仍须在没有开发服务器时可打开。

## 选择图形化对象

适合图形化的内容包括：

- 苯环、稠环、支链和需要看清连接位置的骨架；
- 醛基、羧基、酯基、酰胺基等容易因邻接关系混淆的官能团；
- 加成、消去、取代、氧化等反应中消失或形成的键；
- 同分异构、取代位置、环内外关系，以及任务确实涉及的立体化学；
- 需要从目标结构逆推出直接前体的局部拆键关系。

通常继续使用文本的内容包括：

- 学生需要书写的反应方程式和条件；
- 乙醇、乙醛、乙酸等短小且清晰的缩写结构式；
- 学生作答输入、可复制的结构简式和检索关键词。

不要把同一页面中的所有分子都改成图。推荐采用“局部结构图 + 对应结构简式 + 文字解释”的组合，并要求学生说明图中的连接关系。

## 生成方式

- 少量常见结构优先使用代码确定性绘制的内嵌 SVG。键、原子标签、取代位置和反应箭头应是可单独检查的矢量元素。
- 大量或复杂结构可由 RDKit、Open Babel、SmilesDrawer 等根据已核对的 SMILES、SMARTS 或其他结构数据生成，再进行人工化学校验。
- 若使用可复用 SVG，简单内容可内嵌；数量多时放入 `assets/molecules/`。不得为复用而牺牲离线可用性。
- 图像生成模型只可用于不承担化学事实的情境插画或装饰图。不要让其绘制结构式、反应机理、电子式、轨道图或其他需要逐键准确的内容。

## 表达规则

- 键线式中的顶点和线端按约定代表碳原子；杂原子、必要的氢、形式电荷和立体信息不得遗漏。
- 苯环可使用规范的交替双键式或六边形加内圆表示离域大π键；同一教学语境中保持表示方式一致，并在需要时解释两种表示的关系。
- 展示官能团差异时，可突出羰基碳直接相连的 H、OH、O—R′ 或 N，但必须同时用标签或说明指出差异，不能只依靠颜色。
- 展示反应时，把反应物与产物的对应骨架对齐，明确标出形成、断裂或改变的键；反应试剂、催化剂、温度和可逆性仍以文字或规范符号给出。
- `R`、`R′` 等占位符首次出现时说明其表示其余碳链或基团，不得让学生误认为固定元素符号。

## 准确性检查

逐图检查：

- 原子连接顺序与目标结构一致；
- 每个原子的价键数、形式电荷和必要氢原子合理；
- 环大小、芳香性、双键位置和取代位置正确；
- 官能团方向及其直接邻接原子正确；
- 需要表达时，顺反、手性和构象信息没有丢失或反转；
- 结构图、名称、分子式、结构简式和题目答案彼此一致；
- 反应前后碳骨架、关键原子及电荷去向可解释；
- 箭头、条件、反应类型和可逆符号表达正确。

不能只凭图形“看起来合理”通过校验。复杂或高风险结构应回到权威结构数据或确定性化学工具复核。

## 与 ICAP 结合

- **Passive：** 学生观察结构图并阅读对应结构简式。
- **Active：** 学生标出官能团、圈出变化的键、匹配图与名称或比较两个局部结构。
- **Constructive：** 学生把结构简式画成键线式、从图中生成反应解释、补全缺失结构、预测结构变化或自行建立转化网络。

不要把“看过动态图”或“点过官能团”当作 Constructive。达到 C 阶段必须要求学生外显地产生新的结构、解释、预测或关系，并用价键、守恒、性质或条件进行校验。
